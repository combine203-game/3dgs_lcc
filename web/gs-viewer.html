操作说明
  • 左键拖动 旋转视角
  • 右键拖动 / 双指 平移
  • 滚轮 拉近 / 拉远
  • F 自动取景（回到全景）
  • R 重置相机
  • F11 全屏，1 / 2 / 3 切换「1层室外 / 1层室内 / 三层室内」
  • 顶栏三个按钮 各自直达对应出生点，点按即可重置到该机位
  • W / A / S / D 碰撞漫游（官方 PLY + btree 驱动，不会穿墙）
  • 顶栏「碰撞」按钮 / C 开关碰撞（默认开启，贴地漫游不穿墙；关闭后可自由飞行）
  • 顶栏「局域网」 查看并复制其他设备可用的访问地址（服务默认绑定 0.0.0.0）
  • 顶栏速度滑杆 / [ ] 调节 WASD 与摇杆快慢（0.25×–4×，自动记忆）
  • Shift / Ctrl 按住临时加速 / 减速（引擎自带）
  • 顶栏「工具」/ T 打开资产信息、出生点标定与碰撞体调试面板
  • B 开关碰撞分块包围盒，V 开关碰撞网格线框（引擎内置）
  • L 开始/停止录制漫游，P 播放/停止路线（工具面板「漫游录制」）
  • M 或顶栏「小地图」按钮 显示/隐藏左下角三维导航小地图；在小地图上拖动旋转、滚轮缩放、双击复位
  • N 或顶栏「深度」按钮 打开3DGS 深度视口（浮动窗，主画面不受影响）：当前相机视角的实时深度图（近亮远暗、品红＝无表面），拖标题栏移动、拖右下角缩放，再按一次关闭；视口底部图例可切换映射远界 15/30/60/120 m。视口区域不吃指针，旋转 / 漫游手势可穿过它继续操作主画面。注意快捷键是 N 不是 D——D 是 WASD 的「右移」，按住 D 漫游只会移动、不会关掉视口
  • 顶栏「Mesh深度」 再开一个碰撞 Mesh 深度视口（右侧，青绿边框）：把碰撞网格按同一机位、同一 near/far、同一对数映射渲成深度图，和 3DGS 深度并排比对 —— 两边不一致的地方就是「碰撞体表面」与「splat 表面」不贴合的地方（贴花投射 / 贴地漫游都吃这份几何）。首次打开会顺带打开 3DGS 视口

默认加载流式 LCC（合并自 viewer_stream）：官方 .lcc2 八叉树分块**原样**加载（lcc2-sog-result/data/3dgs，不做任何清理或遮罩），按视野 / LOD 距离按需请求，不再一次性下载整包。改动参数：?source=sog 回到原始未清理的单文件 SOG（mm_floor1.sog / mm_floor3.sog，可配 ?content=./sog/xxx.sog）、?budget=N 覆盖渲染预算（百万点，一层默认 10M）、?mask=1 换「超大高斯透明化」对照版（远景会发暗，不建议）、?stream=1 显示流式观测 HUD、?fullload=1 跳过首帧粗档。两条链路的同机位画质对照见 tools/compare_stream_vs_sog.mjs（tools/shots/stream_vs_sog*/）。碰撞网格取自原始 meta.lcc2 工程，官方米制 Z-up 顶点仅做 world = (x, z, -y) 轴变换，与 3DGS / 出生点 / 漫游路径同处一个米制世界。推荐使用 Chrome / Edge 并保持硬件加速开启：本机 127.0.0.1 访问默认使用 WebGPU；用局域网 IP 打开时因非安全上下文只能走 WebGL2，顶栏徽标会显示具体原因（安全上下文下可点击重试）。
