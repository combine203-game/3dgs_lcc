操作说明
  • 左键拖动 旋转视角
  • 右键拖动 / 双指 平移
  • 滚轮 拉近 / 拉远
  • F 自动取景（回到全景）
  • R 重置相机
  • F11 全屏，1 / 2 / 3 切换「1层室外 / 1层室内 / 三层室内」
  • 顶栏三个按钮 各自直达对应出生点，点按即可重置到该机位
  • W / A / S / D 碰撞漫游（官方 PLY + btree 驱动，不会穿墙）
  • 顶栏「碰撞」按钮 / C 开关碰撞（默认开启，贴地漫游不穿墙；关闭后可自由飞行）
  • 顶栏「局域网」 查看并复制其他设备可用的访问地址（服务默认绑定 0.0.0.0）
  • 顶栏速度滑杆 / [ ] 调节 WASD 与摇杆快慢（0.25×–4×，自动记忆）
  • Shift / Ctrl 按住临时加速 / 减速（引擎自带）
  • 顶栏「清理」/ G 在原始场景与模糊点清理版之间切换
  • 顶栏「工具」/ T 打开高斯清理、出生点标定与碰撞体调试面板
  • B 开关碰撞分块包围盒，V 开关碰撞网格线框（引擎内置）
  • L 开始/停止录制漫游，P 播放/停止路线（工具面板「漫游录制」）
  • M 或顶栏「小地图」按钮 显示/隐藏左下角三维导航小地图；在小地图上拖动旋转、滚轮缩放、双击复位

默认加载已清理模糊高斯的完整 LOD0 单文件 SOG（mm_floor1_clean.sog / mm_floor3_clean.sog）；碰撞网格取自原始 meta.lcc2 工程，官方米制 Z-up 顶点仅做 world = (x, z, -y) 轴变换，与 3DGS / 出生点 / 漫游路径同处一个米制世界。推荐使用 Chrome / Edge 并保持硬件加速开启：本机 127.0.0.1 访问默认使用 WebGPU；用局域网 IP 打开时因非安全上下文只能走 WebGL2，顶栏徽标会显示具体原因（安全上下文下可点击重试）。
